# Euphonium
Baritone is quite bare bones, so I made it more customizable.

# How?
I found a way to basically "hijack" the A* process so I can "inject" my own "rules" for A* to follow (A* is the pathfinding algorithm Baritone uses, for non-nerds).

You can fully edit how Baritone will operate (in the pathfinding aspect). Such as making the bias for parkour be way higher, making Baritone HATE water, take the WORST possible path, etc...

YOU MUST HAVE METEOR CLIENT INSTALLED TO EDIT THESE, and obviously Baritone.
